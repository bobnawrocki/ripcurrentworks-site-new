# RipCurrent Works landing page

This folder contains a simple static landing page for `ripcurrentworks.com`.

## Files
- `index.html` — single-page site

## Deploy to Cloudflare

### Option 1: Cloudflare Pages (easy)
1. Create a new Pages project.
2. Upload this folder or connect a repo containing it.
3. Set the custom domain to `ripcurrentworks.com`.

### Option 2: Direct static hosting
1. Upload `index.html` to any static host.
2. Point DNS at that host from Cloudflare.

## Notes
- The page currently uses `hello@ripcurrentworks.com` as the contact address.
- If email is not set up yet, change the mailto link before going live.
